# Add CivicConnect Screenshot

Please add a screenshot of the CivicConnect dashboard to this folder.

## Required File
- **Filename**: `civicconnect.png`
- **Location**: `/Users/brian/Documents/bryhuang9.github.io/public/civicconnect.png`

## Recommended Screenshot
Use the **Dashboard - Command Center** view showing:
- KPI cards (Infrastructure Assets, Events, Active Alerts, Response Time)
- Event Volume chart
- Asset Distribution pie chart
- Recent Events list
- District Overview

## How to Add
1. Take a screenshot of the CivicConnect dashboard at http://localhost:3000
2. Save it as `civicconnect.png`
3. Place it in the `public/` folder of this portfolio project
4. Delete this instruction file

## Alternative
You can also use one of the screenshots you already took and rename it to `civicconnect.png`.
